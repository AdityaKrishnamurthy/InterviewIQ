# InterviewIQ — AI Technical Interview Agent

> **Your AI Interview Coach.** Upload your resume, pick a company, and get interviewed by an AI that adapts to your answers in real time.

InterviewIQ simulates a real technical interview. It reads your resume, tracks how the session is going, and dynamically decides the next question — harder if you're doing well, back to basics if you're struggling.

## Features (planned)
- 📄 **Resume parsing** — AI extracts your projects, skills, and experience
- 🎯 **Adaptive Q&A** — difficulty adjusts after every answer
- 🏢 **Company personas** — Google (algorithms), Amazon (behavioral/LP), Startup (systems)
- 🔍 **Truthfulness checker** — cross-checks claimed skills against demonstrated knowledge
- 🧠 **Interview memory** — circles back to weak points mid-session
- 📊 **Final report** — per-skill confidence scores, strengths, weaknesses, and improvement roadmap
