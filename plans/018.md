# Plan 018 — Full UI/UX Redesign: "The Record"

## Goal
Replace InterviewIQ's visual system end-to-end. The prior design (Plan 001) was a generic dark-purple/teal "AI SaaS" look — soft glassmorphic cards, gradient buttons, pill badges, emoji-as-icons. The user asked for a complete, bolder visual overhaul (open to changing anything except the product name), executed via the Impeccable design skill's full "create or replace the visual world" flow rather than an incremental polish pass.

Assigned direction (Impeccable `concept-seed` roll, seed key `893de270`, direction-scope, mode `operate`): a **courtroom deposition / legal transcript record**. This isn't decorative — it's a literal match for the product's actual mechanism: the Resume Truthfulness Checker cross-examines resume claims against demonstrated answers, exactly like testimony checked against fact. The interview itself becomes a numbered, timestamped transcript rather than a chat-bubble UI; the final report becomes "the ruling" rather than a generic dashboard.

Weighed against Impeccable's 6 catalog challengers (ocean deep-dive, gravity rain garden, aircraft instrument six-pack, depot split-flap board, Kraftwerk Man-Machine, monochrome product marketing) — 3 declined outright (wrong register/mode for an Operate-mode app), 1 competitive (aircraft instruments — donated a "trend-aware confidence indicator" raise), 2 declined but donated raises (split-flap's decisive snap-step transitions; Kraftwerk's literal "wired" connector for Interview Memory recall). Full reasoning is in the conversation transcript; the direction contract itself is embedded as an HTML comment in `client/index.html`'s `<body>`.

This plan also folds in the unresolved P1/P2 findings from the pre-redesign `/impeccable audit` (Plan 016 follow-up): dead mobile CSS for the interview screen, inline-style sprawl preventing responsive behavior, missing accessible name on the mic button, no `prefers-reduced-motion` support — all fixed as part of the rebuild rather than as a separate pass, since the same files were being rewritten anyway.

## What was done

### Design system (`client/src/index.css`, `client/index.html`)
- New token system: paper stays paper-toned (`--bg-surface`, warm ivory) in **both** themes; only the desk (`--bg-main`) goes dark ("lamplit desk at night") or light ("courthouse-stone daylight"). Ink (`--ink`) is a single near-black value used on paper in both themes — it never has to switch.
- One committed accent family per the Restrained-for-Operate color strategy: deep ink-blue (`--primary`) for actions, stamp-green (`--success`) for confirmed/verified, aged-amber (`--warning`) for caution, and exactly one sealed-red (`--seal`) reserved for truthfulness flags and destructive actions — not the old dual-purpose purple.
- Typography: Libre Caslon Text (headings — legal-document register), Archivo (UI chrome/labels — workhorse Operate-mode sans), Courier Prime (the transcript/record itself — a real typewriter face, not a "technical" mono costume).
- Near-square document radii (2–4px, was 6–16px pill-shaped), real offset+blur paper shadows (removed all colored glow halos), decisive snap-step motion (`cubic-bezier(0.16, 1, 0.3, 1)`, not spring/bounce easing — the Impeccable detector flagged an initial bounce-easing choice and it was corrected).
- All colors verified ≥4.5:1 contrast (WCAG AA) via manual computation, since the detector's HTML/CSS parser was unavailable in this environment (degraded mode — regex-only, no contrast checking) — several initial values (`ink-muted`, `text-muted`, `warning`, `primary` in dark theme) failed AA and were darkened/adjusted.
- `prefers-reduced-motion` alternatives added for every looping animation (mic pulse rings, waveform bars, icon spinner).

### Icon system (`client/src/components/Icon.jsx`, new file)
Hand-authored SVG icon set (one consistent 1.75 stroke weight) replacing every emoji-as-icon across the app — a hard ban in Impeccable's craft-floor reference. Zero new npm dependencies.

### Every page rebuilt in the new world
- `Logo.jsx` — new notarial-seal mark (name "InterviewIQ" kept per explicit product decision, logo mark changed).
- `Login.jsx` / `Register.jsx` — "case intake" framing.
- `Dashboard.jsx` — the "case docket": ledger-style stats row, case-file session list, no icon-cards.
- `ResumeUpload.jsx` — "submitting evidence."
- `InterviewSession.jsx` — the core rebuild: numbered, timestamped transcript lines replace chat bubbles; persona selection is a docket list, not an icon-card grid; fixed the dead `.interview-chat-container`/`.interview-chat-bubble` CSS from the pre-redesign audit by properly wiring the new `.transcript`/`.transcript-line` classes; added the missing `aria-label` on the mic button.
- `FinalReport.jsx` — "the ruling": removed the detector-flagged `border-left` accent (the exact AI-slop tell from the original audit), tab bar instead of card grid.
- `SessionHistoryList.jsx`, `ScoreTrendChart.jsx` — token/icon updates, removed a decorative SVG glow filter (craft-floor bans zero-offset colored halos).
