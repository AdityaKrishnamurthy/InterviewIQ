# Plan 006 — Truthfulness Checker + Interview Memory

## Goal
Implement a truthfulness checker to cross-check claimed vs demonstrated skills and add interview memory to recall weak points mid-session.

## Prerequisites
Plan 005 Done.

## Drift-Check
Run this command to verify the repo is in the expected state:
```powershell

```

## Steps

### Step Group 1: Interview Memory Mid-Session
**Files touched:** `server/src/routes/session.js`
**What to do:** In `POST /api/session/answer`, before generating the next question, inject weak points (score <= 2) from earlier in the session into the Gemini system prompt as "Earlier struggles: ...". This allows Gemini to circle back to weak points.
**Verification:** Logs confirm weak points are appended to the system prompt when applicable.

### Step Group 2: Truthfulness Checker End-of-Session
**Files touched:** `server/src/services/report.js`
**What to do:** After the session ends, for each claimed skill in the resume, find answers in the session that tested it. Ask Gemini to rate the demonstrated knowledge 1-5 based on session answers. Store this as a `skillConfidence` object on the Session document.
**Verification:** `skillConfidence` is populated correctly on session end.
