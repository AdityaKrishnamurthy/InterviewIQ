## Steps

### Step Group 1: Server Session & Adaptive Logic
**Files touched:** `server/src/models/Session.js`, `server/src/routes/session.js`
**What to do:**
Create Session model: `userId`, `resumeId`, `companyPersona`, `messages:[{role,content,score}]`, `currentDifficulty`, `topicHistory`.
Implement POST `/api/session/start` and POST `/api/session/answer`.
Define Company Personas (stored as system prompt modifiers):
- **Google**: algorithms-heavy, asks LeetCode-style problems, follow-ups on complexity
- **Amazon**: behavioral/leadership principles (STAR format), system design
- **Startup**: systems+projects-heavy, architecture, scaling decisions, pragmatic trade-offs

Adaptive logic: after Gemini scores answer 1-5:
- If score >= 4 → increase difficulty
- If score <= 2 → drop to fundamentals
- If score == 3 → lateral topic

Gemini orchestration: 
System prompt = persona + resume context + session history.
User turn = candidate answer.
Assistant determines next question.
**Verification:** Session API handles interactions and adapts difficulty based on mock answers.
