# Plan 004 — Resume Upload + AI Parsing

## Goal
Implement PDF upload and parsing using Gemini API to extract projects, skills, and experience.

## Prerequisites
Plan 003 Done.


## Steps

### Step Group 1: Server Resume Parsing
**Dependencies:** `multer`, `pdf-parse` (if not installed, stop and ask user).
**Files touched:** `server/src/routes/resume.js`, `server/src/models/Resume.js`, `server/src/services/gemini.js`
**What to do:**
Install dependencies in `server`:
```bash
npm install multer pdf-parse
```
Create Resume Mongoose model linked to user.
Create POST `/api/resume/upload` using multer to save to `/uploads/`, run `pdf-parse`, and send text to Gemini.
Prompt template for Gemini: 
```json
{
  "prompt": "Extract from the following resume text: {projects:[{name,description,techStack}], skills:[string], experience:[{company,role,duration}]}"
}
```
Save parsed data to the database.
**Verification:** API route successfully parses a mock PDF and saves data.

### Step Group 2: Client Resume Upload Page
**Files touched:** `client/src/pages/ResumeUpload.jsx`
**What to do:** Create a drag-and-drop zone for PDF files. Show upload progress, and display parsed skills/projects preview after upload.
**Verification:** Page renders correctly and handles upload.
