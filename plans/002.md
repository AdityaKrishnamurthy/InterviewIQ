# Plan 002 — Project Scaffold

## Goal
Set up the monorepo structure, including a Vite React frontend, an Express backend with MongoDB connection, environment variables, Prettier/ESLint, and git initialization.

## Prerequisites
Plan 001 Done.

## Drift-Check
Run this command to verify the repo is in the expected state:
```powershell
if ((Test-Path "client") -or (Test-Path "server")) { Write-Output "client or server dir already exists" } else { Write-Output "Ready" }
```

## Steps

### Step Group 1: Init Root and Configs
**Files touched:** `package.json`, `.gitignore`, `.env.local`
**What to do:** 
Create monorepo root config.
```bash
npm init -y
```
Update `package.json` with workspaces:
```json
{
  "name": "interviewiq",
  "version": "1.0.0",
  "workspaces": ["client", "server"]
}
```
Create `.gitignore`:
```
node_modules
.env.local
dist
build
```
Create `.env.local` (never committed):
```env
GEMINI_API_KEY=your_key_here
MONGO_URI=mongodb://localhost:27017/interviewiq
JWT_SECRET=your_jwt_secret
PORT=5000
```
**Verification:** Root files exist.

### Step Group 2: Scaffold Client
**Files touched:** `client/*`
**What to do:** 
Scaffold Vite React app in `client`.
```bash
npx -y create-vite@latest client --template react
cd client
npm install
```
**Verification:** `client/package.json` exists.

### Step Group 3: Scaffold Server
**Files touched:** `server/*`
**What to do:** 
Scaffold Express server in `server`.
```bash
mkdir server
cd server
npm init -y
npm install express cors dotenv mongoose jsonwebtoken bcryptjs
mkdir src src/routes src/controllers src/models src/middleware src/services
```
**Verification:** `server/package.json` and `server/src` exist.

### Step Group 4: Placeholder Files
**Files touched:** `client/src/App.jsx`, `server/src/server.js`
**What to do:** 
Update `client/src/App.jsx` to output a simple Hello World.
Create `server/src/server.js`:
```javascript
const express = require('express');
const app = express();
const PORT = process.env.PORT || 5000;

app.get('/', (req, res) => res.send('Express Hello World'));

app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```
**Verification:** Files contain correct code.
